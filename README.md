# Chess Like Board Initializer

takes a file containing the definitions of board size and piece locations and initializes a board, printing it to the console.

## Instructions for Build and Use

Steps to build and/or run the software:

1. ensure you have both the .exe file and a game file
2. execute the .exe file from the commandline with an argument pointing to the game file.
3. if you just downloaded this repo, an exampe execution would be: .\Chu-Shogi.exe games/Chess.txt

Instructions for using the software:

1. There is no user input. Just run and sit back.
